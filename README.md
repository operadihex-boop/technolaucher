# Techno Launcher

A customized Minecraft launcher based on [Prism Launcher](https://github.com/PrismLauncher/PrismLauncher), with a clean dark-violet Techno theme, refreshed app branding and the familiar instance/mod/version management workflow.

## Features

- Manage separate Minecraft instances
- Install and manage loaders, mods, modpacks, resource packs and worlds
- Configure Java and memory per instance
- Techno Dark theme with violet and cyan accents
- Windows x64 build support

See [TECHNO-LAUNCHER-README.md](TECHNO-LAUNCHER-README.md) for build notes.
